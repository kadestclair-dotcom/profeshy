# Profeshy

Profeshy is a profession companion app for World of Warcraft: Forever.
Android first. iOS later, once the Android version is finished.

It is a personal project, built in the open and still in early
development. Right now I am checking that the data the app would rely
on actually holds up, before building any features on top of it. So
far that has meant measuring Blizzard's auction house API, checking
recipe and profession data, and working out how price history would
be collected and stored.

Planned features, in rough order:

- Auction house prices and search
- Price tracking and a wishlist
- Crafting profit worked out from live material prices
- Profession leveling guides, with the cost and profit at each step
- A materials list for what you want to craft
- Price history, and forecasts once there is enough history behind
  them to be honest about

Game and auction data comes from Blizzard's API. Some item details
come from ForeverDB.

Data from [ForeverDB.net](https://foreverdb.net)
