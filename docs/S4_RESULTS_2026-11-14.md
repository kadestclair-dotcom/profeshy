## 2. Reagents resolve at 100% — the 53% gap does not reach the recipe graph (P3)

From the first 400 recipe details (of 2,494; sorted by ID, 16% sample —
stated plainly, not a random sample): **192 distinct reagent items,
192 resolved via `/data/wow/item/{id}` = 100.0%**, and 100% within
every one of the 9 professions represented. Crafting's core materials
are present in Blizzard's static data even though the auction house's
long tail is not. S1b's 53% and S4's 100% are both true; they measure
different item populations (everything players list vs. what recipes
consume).

## 3. The media twist (P4/P5)

Against S1b's 25 known-404 item IDs:

- **Item search: 0/25** — no help.
- **Media endpoint: 25/25 return HTTP 200** — media records exist for
  every item whose data record 404s. (Status-level evidence; whether
  each carries a usable icon asset is a one-step follow-up check.)
- For items that *do* resolve, icons are reliable: **50/50 sampled
  resolved items have an icon asset** (P5).

So the gap is specifically item **data** (name, stats, description) —
not icons. For roughly half of auction listings, Blizzard alone can
offer an icon and an ID, but no name.
